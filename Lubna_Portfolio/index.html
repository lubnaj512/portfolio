Indoor Navigation System

Problem

GPS doesn't work inside buildings, so finding your way around a large campus indoors is hard.

Solution

BLE beacon proximity plus IMU-based sensor fusion (dead-reckoning) tracks the user's position, and A* pathfinding computes the best route in real time. A React Native app shows live location; a web admin dashboard manages maps, beacons and navigation data.

My role

Team of 3. I worked across the stack: the React Native app with Zustand state and live tracking, and the Firebase/Firestore backend with the companion admin dashboard.

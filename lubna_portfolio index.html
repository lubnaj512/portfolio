Featured Work

// Final Year Project

Indoor Navigation System

React Native · BLE Beacons · Sensor Fusion · Firebase

An end-to-end indoor navigation system built for CUST campus — solving GPS-denied navigation by fusing BLE beacon proximity with IMU dead-reckoning, then routing users in real time with A* pathfinding.

  • Designed and built the full pipeline: BLE beacon proximity detection + IMU-based sensor fusion for dead-reckoning positioning indoors, where GPS doesn't reach.
  • Implemented A* pathfinding over a 163-node, 165-edge campus graph to compute optimal real-time routes for users on the move.
  • Built a cross-platform mobile app in React Native with Zustand for state management, streaming live location updates at a 700ms refresh interval.
  • Integrated a Firebase/Firestore backend with a companion web admin dashboard for managing maps, beacons, and navigation data.
  • Collaborated with a 3-person team across sensing, algorithms, and app layers to deliver a fully working demo.
